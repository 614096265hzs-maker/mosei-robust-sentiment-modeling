# 实验设计文件说明

先阅读《完整实验方案.md》。它定义数据边界、模型公式、对照关系、缺失生成规则、模型选择、统计分析和解释验证。

| 文件 | 用途 |
|---|---|
| 完整实验方案.md | 完整设计正文，执行时的主要依据 |
| 实验协议.json | 可供后续程序读取的参数与约束；编码器和搜索结果尚未确定，保留null |
| 训练运行清单.jsonl | 8次预搜索＋36次正式训练，逐行列出依赖和种子 |
| 评估条件清单.jsonl | 15个选模条件、85个主评估条件、140个随机位置条件 |
| 结果记录模板.json | 运行、指标、逐样本预测、掩码、对齐和解释字段模板 |
| 生成实验清单.py | 使用Python标准库生成上述机器可读文件；不训练模型 |
| 清单核验摘要.json | 数量、依赖和基本约束核验摘要 |

所有实验目前是planned状态。44次训练不包含可选扩展，也不意味着已经运行。240行评价条件是三种用途的清单总和，正式主比较只使用E-main的85个条件。

生成清单（会重写本目录中由脚本生成的5个设计文件，不改动原始数据）：

```powershell
python 'protocol/生成实验清单.py'
```

只检查现有清单：

```powershell
python 'protocol/生成实验清单.py' --check
```

`modeling/` 已新增读取、核心模型、缺失掩码、训练调度、Q1提取和索引级解释代码，但本仓库尚未执行正式实验。部分补充实验与人工核验仍待完成；清单本身不能替代训练结果。

开始正式训练前优先解决：text_bert对应词表/编码器身份、零值可用性约定、附件4的特征到视频映射。映射工作可在模型开发期间进行，但解释交付前必须逐条报告验证状态。
